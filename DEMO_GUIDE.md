# AtlasIQ Recruiter Demo Guide

## 90-second version

1. **Open with the thesis:** “AtlasIQ turns disconnected student and dataset signals into explainable decisions, entirely in the browser.”
2. **Create a local profile:** Show that any university and major can use the product, while Purdue receives a dedicated campus pack.
3. **Semester Simulator:** Change work or sleep, compare scenarios, and open Ripple Engine to show uncertainty-aware counterfactual modeling.
4. **Opportunity Radar:** Paste a job description and show skill match versus evidence coverage.
5. **ProofGraph:** Add a quantified artifact so a résumé claim becomes inspectable evidence.
6. **Amy:** Ask “What should I do next?” to demonstrate context-aware reasoning across the user’s current workspace.
7. **Studio:** Load a dataset, run AutoML, ask Amy to explain the result, then save it to the profile-scoped Data Vault.
8. **Close with Atlas Passport:** Export a portable portfolio snapshot and explain the privacy model.

## Strong interview talking points

- No framework or runtime dependency is required for deployment.
- Profiles are isolated with scoped localStorage keys; datasets use IndexedDB.
- The app includes regression and classification model comparison, not fabricated model outputs.
- Amy is honest about being on-device in the static release and does not expose an API key.
- Decision Memory creates a feedback loop by comparing predicted and actual outcomes.
- Atlas Pulse is transparent: it combines visible component scores rather than hiding a black-box number.
- Purdue-specific functionality is modular, while custom courses and campus maps support any university.
