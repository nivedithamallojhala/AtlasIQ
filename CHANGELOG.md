# Changelog

## v3 — Universal Workspace + Amy

- Converted the product from a founder-specific demo to profile-scoped multi-user local workspaces.
- Added guest mode, profile creation, profile switching, export/import, and deletion.
- Added generic courses, custom courses, custom campuses, and non-Purdue defaults.
- Rebuilt ProofGraph around each visitor’s skills and evidence.
- Added Opportunity Radar, Decision Memory, Atlas Pulse, Mission Sprint, Data Vault, and Atlas Passport.
- Added Amy, a context-aware on-device Atlas AI copilot with optional voice input.
- Updated offline caching, documentation, résumé bullets, and privacy messaging.
