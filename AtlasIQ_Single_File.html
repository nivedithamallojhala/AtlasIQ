MODEL METHODOLOGY

What AtlasIQ runs locally

For numeric targets, the browser model arena compares a mean baseline, ordinary least-squares linear regression, k-nearest-neighbor regression, and a one-split decision stump. For categorical targets, it compares a majority baseline, k-nearest-neighbor classification, Gaussian Naive Bayes, and a decision stump. Results use a deterministic 80/20 split and should be treated as educational prototypes—not production validation.

The full-stack roadmap can connect the same interface to Python/FastAPI pipelines for cross-validation, XGBoost, LightGBM, CatBoost, SHAP, model registries, and authenticated datasets.
